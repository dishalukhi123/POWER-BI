🏥 Healthcare Dashboard — Power BI Project

A multi-page Power BI dashboard analyzing hospital admissions, billing, insurance claims, and patient outcomes.

Status: Complete Tool: Power BI Desktop

├── Healthcare_PB.pbix     # Main Power BI report file

📊 Dashboard Overview

The report contains 3 pages, each focused on a different analytical view.

Page 1 — Executive Summary

  • KPI Cards: Total Patients, Total Billing, Avg Length of Stay, Billing per Patient
  • Patient Count by Medical Condition (bar chart)
  • Total Billing by Hospital — Top 10 (bar chart)
  • Patient Distribution by Insurance Provider (donut chart)
  • Slicers: Admission Type, Medical Condition, Admission Year (range slider)

Page 2 — Trends & Detail

  • Count of Admission_Month by Admission_Month_Num and Admission_Year (multi-year line chart)
  • Billing_Rounded by Department (column chart)
  • Count of Blood Type by Age (line chart)
  • Detail Table: Patient-level records — Name, Age, Gender, Medical Condition, Admission Type, Billing Amount, Insurance Provider, Test Results, Risk Flag — with totals row

Page 3 — Billing Analysis

  • Average Billing by Department and Billing Tier (stacked chart — Gold, Platinum, Silver, Standard)
  • Matrix Table: Medical Condition × Insurance Provider, with total billing per combination and grand totals

🗂️ Data Model

Main Table

healthcare_dataset — raw patient-level data including Patient_ID, Name, Age, Age_Category, Gender, Blood Type, Medical Condition, Date of Admission, Discharge Date, Doctor, Hospital, Insurance Provider, Billing_Amount_Fixed, Billing_Rounded, Billing_Tier, Room Number, Admission Type, Admission_Year, Admission_Month_Num, Length_of_Stay_Days, Stay_Category, Medication, Test Results, Risk_Flag.

🎨 Design

  • Theme: Deep maroon/burgundy background with dusty rose card panels
  • Typography: Bold serif header ("Healthcare Dashboard") with a doctor icon
  • Layout: Left-hand filter rail (Admission Type checkboxes, Medical Condition dropdown, Admission Year range slider) persists across all pages

🔧 How to Use

  1. Open Healthcare_PB.pbix in Power BI Desktop.
  2. If prompted, update the data source path to point to your local Database/ folder.
  3. Go to Home → Refresh to pull the latest data.
  4. Use the left-panel slicers (Admission Type, Medical Condition, Admission Year) to filter all visuals on a page simultaneously.
  5. Navigate between Page 1 / Page 2 / Page 3 using the tabs at the bottom.

🛠️ Build Steps Reference

This report was built following a structured practical guide covering:

  1. Data import & cleaning (Power Query)
  2. Column type fixes (Billing_Amount_Fixed → Decimal)
  3. Reference query creation (Condition/Hospital/Insurance/Monthly summaries)
  4. KPI card configuration
  5. Chart visuals (bar, line, donut, stacked column, matrix)
  6. Slicers and cross-filtering
  7. Formatting and theming

📌 Notes / Known Considerations

  • Total_Revenue and other summary fields live inside their respective summary query tables, not the main dataset — expand the correct table in the Data pane when building visuals.
  • Top N filters (e.g., Top 10 Hospitals by Revenue) are applied via Filters pane → Filter type: Top N.
  • Line chart axis sorting (e.g., Admission_Month_Num ascending) should be set via the visual's Sort axis option to avoid month order issues.
